STEP 1

고용24 수강신청

고용24 홈페이지에서 원하는 과정을 검색하고 수강신청을 진행해주세요.

1

고용24 로그인

고용24 로그인 버튼 클릭 후, 간편인증 또는 공동인증서로 로그인해주세요.

⚠️ 공동인증서 로그인은 고용24에 처음 로그인하는 경우 사용할 수 없습니다. 고용24에 처음으로 로그인하시는 경우 간편인증을 선택해주세요!
🌐 고용24 바로가기
2

과정 검색

고용24 훈련과정 검색에서 수강할 과정을 찾습니다.

  • ✅상단 메뉴 [직업 능력 개발 - 국민내일배움카드 훈련과정] 클릭
  • ✅검색어에 [과정명] 입력 또는 훈련기관명에 [패스트캠퍼스분점] 검색
3

수강 신청

원하는 과정을 선택하여 수강신청을 합니다.

  • ✅과정 상세 페이지에서 [수강신청] 버튼 클릭
  • ✅훈련 시작일·종료일 확인
  • ✅훈련기관 약관 동의
  • ✅수강신청을 누르면 개인정보 입력하는 신청서가 나오는데 본인 정보에 맞게 입력
🎉 수강신청 완료! 자부담비 결제를 안 하신 경우 자부담비 결제까지 완료해주세요!

✅ "고용24 신청 + 자부담비 결제"가 모두 완료되시면, 1~2일 내로 최종 훈련생으로 등록하여 안내 카카오톡 알림톡을 발송해드리고 있습니다.
